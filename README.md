# AAA SERVICE — проект для GitHub и Cloudflare Workers

Экспорт от 24 сентября 2026 года. Структура архива соответствует экспорту AAA URBAN: npm, package-lock.json, wrangler.jsonc и отдельные папки страниц. Дизайн и тексты AAA Service сохранены.

## Загрузка в GitHub

1. Распакуйте ZIP и откройте папку, в которой лежит `package.json`.
2. Загрузите её содержимое в корень репозитория `assemprod/aaaservice`, сохраняя вложенные папки. В корне должны находиться `package.json`, `package-lock.json`, `vite.config.ts`, `wrangler.jsonc`, `app`, `components`, `public`, `lib`, `scripts`, `vendor`.
3. На странице GitHub выберите **Add file → Upload files**, перенесите содержимое папки и дождитесь завершения загрузки. Нажмите **Commit changes**. Сам ZIP в репозиторий загружать не нужно.
4. Если обновляете старый экспорт, удалите старые `pnpm-lock.yaml`, `pnpm-workspace.yaml` и папку `app/[...path]`. Этот экспорт использует npm и отдельные страницы. Остальные старые служебные папки для сборки не нужны.

В архиве меньше 100 файлов. Для работы сборки не требуется загрузка скрытых конфигурационных файлов. Если браузер выдаёт ошибку обработки файла, повторите загрузку через другой браузер; наличие файла в окне загрузки ещё не означает, что он сохранён в репозитории.

## Настройки существующего Worker в Cloudflare

| Настройка | Значение |
| --- | --- |
| Worker | `aaaservice` |
| Production branch | `main` |
| Root directory | Корень репозитория, где лежит `package.json` |
| Build command | `npm run build` |
| Deploy command | `npm run deploy:built` |
| Node.js | 22.13+; проверка выполнена на 24.19.0 |

Cloudflare установит зависимости из `package-lock.json`. Для чистой установки вручную используйте `npm ci`. Команда `deploy:built` публикует собранный Worker через `wrangler deploy --config dist/server/wrangler.json`. В закреплённой версии Vinext 1.0.0-beta.5 старая команда `vinext deploy` удалена, поэтому используйте команды из этой таблицы.

База данных, R2 и дополнительные секреты этой версии сайта не нужны. `NEXT_PUBLIC_SITE_URL` можно задать при подключении собственного домена; по умолчанию используется `https://aaaservice.corparationsite.workers.dev`.

После коммита дождитесь успешной сборки и публикации. Проверьте адрес `https://aaaservice.corparationsite.workers.dev` и страницы из таблицы ниже.

## Страницы

| Раздел | Русский URL | Казахский URL |
| --- | --- | --- |
| Главная | `/` | `/kz` |
| О компании | `/about` | `/kz/about` |
| Услуги | `/services` | `/kz/services` |
| Кейсы | `/cases` | `/kz/cases` |
| Контакты | `/contacts` | `/kz/contacts` |

Каждой странице соответствует собственный `page.tsx` в `app`. Общий дизайн и содержание находятся в `components/site.tsx`, стили — в `app/globals.css` и `app/reference.css`. Логотип — красная надпись AAA service.

Перед сборкой автоматически проверяются все 10 страниц и основные ресурсы. Если часть файлов потерялась при загрузке, сборка завершится с перечнем отсутствующих файлов.

## Локальный запуск

```bash
npm ci
npm run dev
```

Проверка production-версии:

```bash
npm run typecheck
npm run build
npm start
```

Для публикации с собственного компьютера после авторизации в Cloudflare: `npx wrangler login`, затем `npm run deploy`. Публикация в вашем аккаунте при подготовке архива не выполняется.

# AAA SERVICE — demo website

Статический многостраничный демо-сайт. Его можно загрузить в GitHub без сборки.

## Структура
- `/` — главная
- `/services/` — услуги
- `/services/cleaning/` — профессиональная уборка
- `/services/engineering/` — инженерное сопровождение
- `/services/property-management/` — комплексное управление
- `/about/` — о компании
- `/contacts/` — контакты

## GitHub
1. Создайте новый репозиторий.
2. Загрузите содержимое этой папки в корень репозитория.
3. Для GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.
4. Для Cloudflare Pages: подключите репозиторий и оставьте Build command пустым, Output directory — `/`.

## Важно
Форма заявки сейчас демонстрационная и не отправляет данные на сервер. Для production ее нужно подключить к Bitrix24, email API или другому backend.
